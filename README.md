# 📊 Interactive Sales Dashboard

This project is about analyzing sales data and presenting it in a clear and visual way.  
I created this dashboard to understand how different products, regions, and dates affect overall sales.

The project includes both **simple charts** and an **interactive dashboard** so that data can be explored easily.

## 🎯 Purpose of the Project

The main goal of this project is:
- To practice data analysis using real-like sales data
- To understand product and region-wise sales performance
- To create clean and meaningful visualizations
- To build an interactive dashboard using Plotly
  
## 📂 Dataset Details

**File name:** `sales_data.csv`

The dataset contains the following columns:
- `Date` – Date of the sale  
- `Product` – Name of the product sold  
- `Quantity` – Number of units sold  
- `Price` – Price of one unit  
- `Customer_ID` – Unique customer ID  
- `Region` – Region where the sale happened  
- `Total_Sales` – Total sale amount (Quantity × Price)

## 🛠️ Tools and Libraries Used

- Python  
- Pandas for data handling  
- Matplotlib & Seaborn for basic charts  
- Plotly for interactive dashboard
